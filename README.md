# AI_Notes_Maker


Users can:
- Register and Login
- Upload PDF notes/books
- Extract text from PDFs
- Generate AI-based short notes instantly

---

## Features

- User Authentication
- PDF Upload
- Text Extraction from PDF
- AI Notes Generation
- MySQL Database Connectivity
- Simple Streamlit Interface


---

## Technologies Used

- Python
- Streamlit
- MySQL
- OpenAI API
- PyPDF2

## Installation

### 1. Install Required Libraries

python -m streamlit run app.py // to run frontend .
